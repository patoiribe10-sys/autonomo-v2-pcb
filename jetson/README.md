# Jetson

El código que corre en la Jetson (nodos de ROS 2, cámaras, control de Xbox, visión y navegación) ya no vive en este repositorio. Está en el repositorio del carro completo:

**https://github.com/patoiribe10-sys/robouaq-carro-autonomo**

Aquí se queda lo que es de la placa: el firmware del ESP32 (`firmware/`, incluido `carro-v2` con su `tools/prueba_serial.py`), las pruebas de la PCB, el manual, los planos y la documentación del curso.
